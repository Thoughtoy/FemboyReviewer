System Administration Essentials

1. Intro to System Admin

SysAd = maintains reliable systems in a multi-user/UNIX environment. Not a software engineer.

Skills OS, troubleshooting, networking, security, scripting, problem-solving, teamwork.
Tasks install, backup, configure, troubleshoot, document, educate users.
Company size 20 = does everything alone; 200 = everything + a specialty; 2000+ = very specific duties.
Related roles DBA, Network, Security, Web, Tech Support, Computer Operator.

Remember: "Skip breakfast and payroll, not the backup!" and "Monitor so you don't have to restore."

Open source perks: fix bugs early, contribute, less vendor lock-in, no license headaches.

2. Becoming Superuser

Windows Administrator. Linux/Unix root.
Can do read/write/execute, install, modify, delete users and data.
Account types Administrator > Standard > Guest.
Risks mistakes, malice, malware, backdoors, shared accounts.
Best practices L-D-S-R-M Least privilege, Divide systems, Separate privileges, Rotate passwords, Monitor/audit.
PAM Privileged Access Management — discover accounts, remove admin rights, control elevation (SUPM), secure passwords, audit sessions.

3. User Interface

UI point of human-computer interaction.
2 components Presentation (computer → human) and Action (human → computer).
6 types Natural-language, Question-and-answer, Menu, Form-fill, Command-language, GUI.
Design objectives Effectiveness, Efficiency, User consideration, Usable queries, Productivity.
Dialog (3 points) Meaningful communication, Minimal user action, Standard operation.
Help types F1, pull-down menu, context-sensitive, icon hover, wizard, help desk, forums.

4. Unix

Portable, multitasking, multi-user OS — made by programmers for programmers.

Kernel manages memory, I/O and processes.
Shell interpreter between user and computer; provides pipes (output of one command becomes input of another).
Multi-user OS functions command interpretation, peripheral, memory and process management.
SysAd tasks in Unix make files available, monitor disks, backups, file security, add disks/tapes.

5. User Accounts & Groups

User account one person.
Group collection of accounts; permissions granted all at once.
Admin console add, edit, delete and disable accounts and groups.
Disable keeps the person's content. Delete removes them.
Account info profile, password, enabled, activity, visibility, group membership, email notifications, avatar, properties.

Users can self-register (username + password + profile).

6. Essential Admin Tools (C-P-T-D-A-T)

C — Communication email, Slack/Teams, Zoom
P — Project mgmt Trello, Asana, Jira, Google Workspace/M365
T — Time mgmt time blocking, priorities, calendar
D — Data security cybersecurity, backup/recovery
A — Automation Zapier, Power Automate, chatbots, AI
T — Training continuous learning, skill development

Good practice = reproducible tasks, know your config, patches and services, and keep learning.

7. Startup & Shutdown

Boot P-B-B-K-D POST → BIOS/UEFI → Boot loader → Kernel loading → Device init and user space.
Shutdown C-S-T-F-H Close apps → Save settings → Terminate processes → File system ops → Hardware power off.
Why it matters (7) integrity/stability, resource mgmt, security, updates, user experience, preventing data loss, energy efficiency.

8. TCP/IP

IP address + route (where does it go?).
TCP reliable, ordered delivery (did it all arrive?).
4 layers (top → bottom) Application (HTTP, DNS) → Transport (TCP) → Internet (IP) → Network (Ethernet/Wi-Fi).
IPv4 / IPv6 32-bit / 128-bit. IP = device, port = service.
TCP vs UDP TCP = reliable (web, email, files); UDP = fast, no acknowledgment (video, games, DNS queries).
Devices/services DNS (name → IP), DHCP (auto-assigns IP), gateway, switch (same LAN), router (between networks), firewall.
Troubleshoot basics → config → ping 127.0.0.1 → own IP → gateway → remote → nslookup → traceroute.
Network types LAN, WAN, MAN, WLAN, CAN, SAN.

9. Security

CIA triad Confidentiality (private), Integrity (accurate), Availability (accessible).
Threats malware, cyber attacks, social engineering, physical threats, unauthorized access, theft/sabotage.
Measures authentication (who are you?) and authorization (what can you do?), encryption, firewall/IDS, policies.
Network segmentation, least privilege, redundancy. Endpoint antivirus, EDR, mobile security.
Cloud IaaS, PaaS, SaaS. Shared responsibility provider secures infrastructure; you secure data and configs.
Standards/laws ISO/IEC 27001, NIST, GDPR, HIPAA.
Trends AI/ML and Zero Trust (trust no one, verify always).

10. Network Services

Core DNS, DHCP, NTP (time sync).
Directory services database of users, systems and resources; hierarchy of entries with attributes (Active Directory, OpenLDAP).
File and print file transfer protocols, print job management.
Email SMTP = Send; POP = Pull down (offline); IMAP = syncs with the server.
Web HTTP and HTTPS (encrypted).
Remote access VPN (secure tunnel to a private network), Remote Desktop (control a computer remotely).
Security access control and encryption in transit.
Memory trick: The whole course comes down to — Backup, Monitor, Least privilege, CIA, ping the gateway.
